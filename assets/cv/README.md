# CV (à ajouter)

Aucun CV PDF n'est encore fourni dans ce dépôt. Pour activer le téléchargement :
1. Placer un CV vérifié dans ce dossier sous le nom `CV-Clement-Dufour.pdf`.
2. Dans `index.html`, remplacer `href="assets/cv/README.md"` par `href="assets/cv/CV-Clement-Dufour.pdf" download`.
3. Mettre à jour les libellés `contact.cv` dans les deux traductions JSON.
Ne pas publier d'informations personnelles non souhaitées dans le CV.
