# Aperçus des projets

Captures produites à partir des projets réels de Clément Dufour, sans illustration générée.

- `fantasy.jpg` : écran d'accueil de The Fantasy 2.7, depuis `game/index.html` dans [The_Fantasy_The_Great_Adventure](https://github.com/Theskater25/The_Fantasy_The_Great_Adventure/tree/459dacf59036a14501d1c902b7801d28effdf86f). Les ressources du jeu et leurs crédits restent documentés dans ce dépôt.
- `mancala.jpg` : premier écran rendu par `mancala.py`, depuis [Mancala-Python-game](https://github.com/Theskater25/Mancala-Python-game/tree/f3b8cff675d77183320731c7054b6b311401e623). Auteurs du jeu : Clément Faure, Clément Dufour et Tom Torrente.
- `blackjack.jpg` : table de la démonstration web disponible dans `demos/blackjack.html` de ce portfolio. Cet aperçu représente la démo JavaScript, pas l'interface du programme Python original.
- `portfolio.jpg` : page d'accueil de cette version du portfolio.

Les aperçus sont stockés dans le portfolio pour éviter une dépendance aux fichiers des autres dépôts. Leurs textes alternatifs sont traduits dans `assets/i18n/fr.json` et `assets/i18n/en.json`.
