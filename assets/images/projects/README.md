# Aperçus des projets

Captures produites à partir des projets réels de Clément Dufour, sans illustration générée.

- `fantasy.webp` : écran d'accueil de The Fantasy 2.7, depuis `game/index.html` dans [The_Fantasy_The_Great_Adventure](https://github.com/Theskater25/The_Fantasy_The_Great_Adventure/tree/459dacf59036a14501d1c902b7801d28effdf86f). Les ressources du jeu et leurs crédits restent documentés dans ce dépôt.
- `fantasy-ii.png` : écran titre de [The Fantasy Great Adventure II](https://github.com/Theskater25/the-great-fantasy-ii), capturé depuis le jeu à 1280 × 800 px.
- `mancala.webp` : premier écran rendu par `mancala.py`, depuis [Mancala-Python-game](https://github.com/Theskater25/Mancala-Python-game/tree/f3b8cff675d77183320731c7054b6b311401e623). Auteurs du jeu : Clément Faure, Clément Dufour et Tom Torrente.
- `blackjack.webp` : table de la démonstration web disponible dans `demos/blackjack.html` de ce portfolio. Cet aperçu représente la démo JavaScript, pas l'interface du programme Python original.
- `portfolio.webp` : page d'accueil de cette version du portfolio.

Les aperçus sont stockés dans le portfolio pour éviter une dépendance aux fichiers des autres dépôts. Leurs textes alternatifs sont traduits dans `assets/i18n/fr.json` et `assets/i18n/en.json`.

- `portfolio-v1.webp` : capture du code original de la première version, consultable sur https://theskater25.github.io/MonUniversInformatique.github.io/v1/. Source correspondante : commit `24863860003f6ea8bbb5f77a32943d96821563c0`. Cette version utilise le thème Hyperspace de HTML5 UP, dont les crédits sont conservés sur la page d'évolution.

## Captures de gameplay

- `fantasy-combat.webp` : premier boss du chapitre I, joué avec le Chevalier.
- `fantasy-inventory.webp` : inventaire après le premier butin de boss.
- `fantasy-skills.webp` : arbre des compétences de ce même héros.

Source : version 2.7, commit `459dacf59036a14501d1c902b7801d28effdf86f` du dépôt du jeu. Captures issues d’une partie jouée par les commandes normales de l’interface, sans modifier les statistiques ni injecter une sauvegarde.

Les aperçus utilisent WebP et une variante plus petite lorsque la résolution d’origine le permet. Les attributs `srcset` et `sizes` laissent le navigateur choisir la ressource adaptée à l’écran. Les fichiers `-640.webp` peuvent avoir une largeur inférieure à 640 pixels pour conserver les proportions.
