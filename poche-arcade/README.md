# Poche Arcade

[Jouer dans le navigateur](https://theskater25.github.io/MonUniversInformatique/poche-arcade/) · [Voir le projet sur le portfolio](https://theskater25.github.io/MonUniversInformatique/generic.html#poche-arcade)

Poche Arcade réunit 47 mini-jeux en français. Le bandeau présente un jeu toutes les six secondes. Recherche une cartouche par nom, par genre ou avec le nom d’un classique comme « 2048 », « Tetris » ou « Puissance 4 ». Chaque cartouche a sa propre adresse et partage le tableau des records du navigateur.

## Jouer en local

Depuis ce dossier, lance `python jouer.py` pour ouvrir le menu des 24 cartouches Python. Il indique lesquelles se jouent dans le terminal et lesquelles ouvrent une fenêtre Pygame. Les nouveaux jeux occupent les numéros 13 à 24. Quitte une partie avec `:q` dans le terminal ou Échap dans la fenêtre pour revenir au menu. Tu peux aussi ouvrir un seul jeu, par exemple `python jouer.py sudoku-des-serres`.

Ouvre `index.html` dans un navigateur moderne pour entrer dans la salle d’arcade. Chaque jeu est aussi accessible par son propre fichier `index.html`. Garde le dossier `assets` à côté des dossiers des jeux. Les fichiers nécessaires sont fournis, y compris les illustrations et les modules WebAssembly.

Pour jouer à **Poste Polaire** dans une fenêtre Python, lance `python poste-polaire/jouer.py` depuis la racine du projet. Cette version utilise Tkinter, les illustrations de la cartouche et le même moteur de déplacement.

### Jouer dans le terminal

Lance `python terminal.py` pour choisir parmi seize jeux de logique, de plateau ou d’aventure. Tu peux aussi ouvrir un jeu directement avec `python terminal.py crypte-des-encres`. Python 3 suffit. Pendant la partie, écris `:q` pour quitter.

Sur les grilles, saisis une coordonnée comme `B3`, ou un numéro de colonne pour Quatre en ligne. À la bataille navale, la commande `pivoter` change l’orientation du bateau et `auto` place toute la flotte. Dans Champ de balises, `!B3` pose ou retire un fanion.

Au sudoku, `B3 7` inscrit un chiffre. Dans Jardin cellulaire, `B3` bascule une cellule, `pas` avance d’une génération et `10` de dix. Dans Gardiens du sentier, saisis la coordonnée d’un socle pour y installer ou améliorer une lanterne, puis `vague` pour lancer les escargots. La commande `finir` déroule toute la vague.

### Jouer avec Pygame

Ruban des bois reprend le principe du serpent, Duel de lanternes celui du duel de raquettes et Atelier vitrail celui du casse-briques. Dans Veille de Saturne, un vaisseau-jardinier disperse trois nuées au pollen. Les versions Pygame et HTML partagent le même moteur Python, les mêmes collisions et le même dessin du terrain.

```sh
python -m pip install -r requirements-jeux.txt
python jeux_2d.py
```

Le menu propose huit jeux, dont Courant de plumes, Quai des formes, Carrière orbitale et Coursier des toits. Pour en ouvrir un directement, lance par exemple `python jeux_2d.py carriere-orbitale`. Appuie sur Entrée pour commencer, sur P pour mettre en pause, sur R pour recommencer et sur Échap pour quitter. Les commandes propres au jeu figurent sous le terrain.

### Servir la collection en local

Pour servir le projet sur une adresse locale, depuis le dossier contenant ce README, lance la commande suivante avec Python 3.

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Ouvre ensuite [la salle d’arcade locale](http://127.0.0.1:8000/). Le serveur permet de partager les records entre les pages sur une même origine. Le comportement du stockage en ouverture directe dépend du navigateur.

## Publier sur GitHub Pages

1. Place le contenu du projet à la racine d’un dépôt GitHub et pousse la branche principale.
2. Dans **Settings → Pages**, choisis **Deploy from a branch**, sélectionne cette branche et le dossier **/(root)**, puis enregistre.
3. Une fois la publication terminée, utilise l’adresse affichée par GitHub Pages dans ton portfolio. Pour présenter un jeu en particulier, ouvre sa cartouche et copie son adresse.

[Configurer une source de publication sur GitHub Pages](https://docs.github.com/fr/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Organisation

Le dossier `assets` regroupe les jaquettes, les styles, la navigation, le son et le stockage des records. Chaque cartouche contient ses propres règles et son interface de jeu.

### Modifier les moteurs Python et C++

Dix puzzles à étapes ont chacun un `moteur.py` pour leurs règles et un `vue.js` pour présenter leur plateau. Cinq jeux d’action à étapes utilisent chacun un `moteur.cpp` et un `piste.js`. Ils partagent le compteur de vies et de points de [manche.hpp](moteurs/manche.hpp). Ces quinze cartouches proposent trois étapes, des commandes clavier et tactiles, et un record par étape.

Les 24 cartouches du menu Python ont chacune un `moteur.py`. Le compilateur produit leur `moteur.gen.js` pour les pages HTML. Les jeux au tour par tour utilisent [l’interface des classiques](assets/classiques.js) ou [les tables de jeu](assets/tables.js). Les huit cartouches d’arcade utilisent [le lecteur 2D](assets/arcade-2d.js) sur le Web et [le lanceur Pygame](jeux_2d.py) sur ordinateur.

Pour Poste Polaire, modifie [le moteur Python](poste-polaire/moteur.py). PScript en produit la version JavaScript pour le navigateur. Les cartes et les règles de glisse sont définies une seule fois.

Pour Halte Lunaire, modifie [la simulation C++](halte-lunaire/moteur.cpp). Le jeu avance à 60 pas par seconde. Le navigateur transmet les commandes des propulseurs au module WebAssembly, puis dessine la position du module et le terrain renvoyés par la simulation.

Les quatre cartes et les réflexions de Minuit au phare sont définies dans [le moteur Python](minuit-au-phare/moteur.py). PScript produit le fichier exécuté par la page. Pour Ricochet Radio, [la simulation C++](ricochet-radio/moteur.cpp) gère les collisions, les fréquences et les points. Le curseur, les touches et les gestes tactiles pilotent la même antenne.

Après une modification des moteurs, reconstruis les fichiers livrés avec les pages depuis la racine du projet. Sous Windows, avec Python 3.12, utilise les commandes suivantes.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r outils/requirements.txt
.\.venv\Scripts\python.exe outils/compiler.py
```

Sous macOS ou Linux, utilise `.venv/bin/python` pour les deux dernières commandes. Ajoute les moteurs générés au même commit que les sources correspondantes. Les visiteurs peuvent ensuite jouer directement en ouvrant les pages.

Les boutons sont accessibles au clavier avec Tab puis Entrée ou Espace. Poste Polaire, Halte Lunaire, Ricochet Radio et Tri Express acceptent aussi les flèches. Le bouton de volume active les effets sonores synthétisés. Les meilleurs scores sont enregistrés dans le stockage local du navigateur.
